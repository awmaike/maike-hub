# Maike Hub V1

Primeira versão funcional do painel pessoal.

## O que já tem

- Dashboard responsivo
- Tarefas com criação e conclusão
- Notas rápidas
- Atalhos
- Barra de comando simples
- Cards de status do PC simulados
- Interface pronta para crescer

## Como rodar

1. Instale Node.js 18+.
2. Abra o terminal dentro desta pasta.
3. Rode:

```bash
npm install
npm run dev
```

4. Abra `http://localhost:3000`

## Comandos da barra

- `tarefa Comprar alguma coisa`
- `nota Ideia para implementar depois`
